# Statements and Records

## Monthly statements
Monthly statements are generated on the first day of each month and cover the previous calendar month. They are available in the mobile app under Documents and can be downloaded as PDF files.

## Custom date ranges
Custom statements can be requested for any period within the last twenty-four months. Select the account, the start date and the end date in the app. A custom statement is usually ready within a few minutes.

## Transaction details
Each transaction row shows the posting date, description, amount and running balance. A transfer description includes the destination reference supplied by the sender.

## Duplicate copies
A duplicate statement costs PKR 200 per statement. Account holders can request duplicates for their own accounts only. Closed accounts remain viewable for seven years.

## Record corrections
If a transaction looks incorrect, contact the helpline with the transaction date and amount. Disputes must be raised within ninety days of the posting date.
